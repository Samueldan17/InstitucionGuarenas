Sistema de Gestión Escolar - Instituto Guarenas
Este es un proyecto académico desarrollado como requisito para la obtención del título de TSU en Informática en la UPTAMCA (Trayecto II).

📝 Descripción
Plataforma web diseñada para la gestión de información escolar de la U.E.N. Guarenas. El sistema busca optimizar procesos administrativos y académicos.

🛠️ Tecnologías Utilizadas
Backend: PHP

Base de Datos: MySQL

Frontend: HTML, CSS, JavaScript

Entorno de desarrollo: XAMPP, VS Code

🚧 Estado del Proyecto
🟡 En desarrollo. Actualmente trabajando en la lógica del backend y la interfaz de usuario.
